# BioSeq Analyzer

**English | [中文](README.zh-CN.md)**

A beginner-friendly Python project for learning basic bioinformatics through **learning by building**.

BioSeq Analyzer is designed for beginners who want to learn bioinformatics-related Python programming by completing a small but functional project instead of studying programming syntax, libraries, and biological data processing separately.

Through this project, you can learn:

* Basic Python syntax and programming concepts
* Common Python libraries used in bioinformatics
* Basic biological sequence processing
* FASTA data handling
* Data visualization
* Exception handling
* Modular programming and basic software engineering practices

## Features

BioSeq Analyzer currently supports:

* Reading DNA sequences from FASTA files
* DNA sequence validation
* Sequence length calculation
* A/T/C/G nucleotide counting
* GC content calculation
* Reverse complement generation
* DNA transcription to RNA
* RNA translation to protein
* Nucleotide distribution visualization
* Saving analysis plots as image files

## Learning Goals

The goal of this project is not to replace professional bioinformatics software.

Instead, it provides a simple and complete workflow for beginners to understand how Python can be used to process biological sequence data.

### Python Basics

The project covers fundamental Python concepts including:

* Variables
* Functions
* Conditional statements
* Loops
* Strings
* Dictionaries
* Sets

* Exception handling

### Bioinformatics with Biopython

The project introduces basic use of **Biopython**, including:

### Biological Sequence Processing

Basic sequence-processing tasks include:

* Sequence validation
* Nucleotide composition

### Data Visualization

**Matplotlib** is used to visualize nucleotide composition and save the analysis result as an image.

### `main.py`

Controls the overall analysis workflow:

```text
Read FASTA
    ↓
Validate sequence
    ↓
Basic sequence analysis
    ↓
DNA → RNA → Protein
    ↓
Generate visualization
```

### `analyzer.py`

Contains basic sequence-processing functions implemented with Python:

* Sequence validation
* Nucleotide counting
* GC content calculation
* Reverse complement generation

### `data/`

Stores FASTA files used as program input.

### `results/`

Stores visualization results generated by the program.

## Requirements

Recommended environment:

* Python 3.13
* Biopython
* Matplotlib

Install the required packages with:

```bash
python -m pip install -r requirements.txt
```

## Installation

Clone the repository:

```bash
git clone https://github.com/hcwwuu/BioSeq-Analyzer.git
```

Enter the project directory:

```bash
cd BioSeq-Analyzer
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Usage

Place a DNA sequence in FASTA format inside the `data/` directory.

Example:

```text
>example_sequence
ATGGCCATTGTAATGGGCCGCTGA
```

Run:

```bash
python main.py
```

The program outputs basic sequence information such as:

```text
Length: ...
Base Counts: ...
GC Content: ... %
Reverse Complement: ...
DNA: ...
RNA: ...
Protein: ...
```

It also generates a nucleotide distribution plot:

```text
results/nucleotide_distribution.png
```

## Why This Project?

Bioinformatics programming can be difficult for beginners when Python syntax, biological concepts, libraries, and data formats are learned separately.

BioSeq Analyzer follows a **learning-by-building** approach.

Instead of learning each concept in isolation, beginners build a complete sequence-analysis workflow and learn the required programming concepts while solving concrete biological problems.

The basic version intentionally remains simple so that beginners can understand the complete workflow before moving on to more advanced bioinformatics projects.
